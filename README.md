# SecurePortScanner

SecurePortScanner is a beginner-friendly cybersecurity project built using Python and socket programming. The tool scans common TCP ports on a target website or IP address and identifies open network services.

## Features
- TCP Port Scanning
- Detects Open Ports
- Fast and Simple
- Beginner Friendly
- Built with Python

## Technologies Used
- Python
- Socket Programming

## How to Run

1. Install Python
2. Download the project
3. Open terminal in project folder
4. Run:

```bash
python scanner.py
```

## Example

```bash
Enter website or IP address to scan: scanme.nmap.org
```
